# Tools

The model may call these tools:

- `status` to read the selected models and the journal check
- `vault_search`, `vault_read`, `vault_write` for markdown notes
- `peer_note`, `peer_read` for Honcho cards
- `ledger_recent` for the hash chain
- `list_files`, `read_file` inside this repository

`replicate`, `dream`, `watch`, and `run` are operator commands. A model reply cannot start them.
